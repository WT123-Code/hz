# Newbox 影视聚合配置（10.30 + 山有木兮）

基于 10.30 的 Newbox / TVBox 系聚合配置，已新增「山有木兮」python 爬虫站点。

## 文件说明

| 文件 | 说明 |
|------|------|
| `10.30.json` | 主配置。`spider` 字段已追加 `山有木兮.jar` 链接；`sites` 数组已新增 `山有木兮` 站点（`api: csp_山有木兮`） |
| `山有木兮.jar` | python 爬虫转成的 jar（**需自行用 py→jar 工具生成**，见下方） |
| `py/山有木兮.py` | 原始 python 爬虫脚本（转换输入） |
| `json/` | 教育分类数据（可选，按需放入） |

## 使用方法

1. Newbox → 设置 → 接口配置
2. 填入本仓库 `10.30.json` 的 **raw 链接**（`https://raw.githubusercontent.com/<用户名>/<仓库>/main/Newbox部署/10.30.json`）
3. 保存并加载

## 山有木兮.jar 的生成

Newbox 只认 jar，`.py` 脚本必须先转换成 jar：

1. 获取 py→jar 转换工具（社区工具 `pyj2x` 等，可通过本脚本作者 QQ 群 **807916734** 或相关 B 站/贴吧分享获取）
2. 用工具加载 `py/山有木兮.py` 进行转换
3. 得到 `山有木兮.jar`（转换产物内部类名应为 `山有木兮`，对应 `api: csp_山有木兮`）
4. 把 jar 上传到本仓库，并将它的 raw 链接替换进 `10.30.json` 的 `spider` 字段（替换 `__JAR_RAW_URL__`），再重新上传 json

## 注意

- `10.30.json` 中 `spider` 的 `__JAR_RAW_URL__` 是占位符，务必替换为 jar 的真实 raw 链接。
- 若转换工具的产物类名不是 `山有木兮`，需同步修改 `sites` 中该站点的 `api` 字段。
- jar 为第三方转换产物，请仅在可信渠道获取转换工具。
